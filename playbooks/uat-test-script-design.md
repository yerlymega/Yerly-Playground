# 📑 Playbook: Enterprise UAT Test Script Design — Yerly-Playground 🌸

Pedoman penyusunan dokumen pengujian User Acceptance Test (UAT) resmi Bank Mega format 4-Sheet Excel.

---

## 1. Standar 4-Sheet Excel Bank Mega

1. **Sheet 1: Cover (Pengesahan)**:
   - Header logo Bank Mega, Nama Proyek, Tanggal UAT.
   - Kolom tanda tangan QA, Project Manager, dan Business Owner.
2. **Sheet 2: Lembar Kontrol**:
   - Catatan versi dokumen, tanggal revisi, perbaikan yang dilakukan.
3. **Sheet 3: Skenario & Traceability**:
   - Matriks keterkaitan antara ID Acceptance Criteria (AC) pada BRD/FSD dengan kode Skenario UAT.
4. **Sheet 4: Test Script Detail**:
   - Matriks langkah detail per langkah pengujian beserta status PASS / FAIL.

---

## 2. Checklist Kelayakan UAT
- [ ] Seluruh nomor AC pada BRD telah memiliki minimal 1 Test Case Positif dan 1 Test Case Negatif.
- [ ] Pengujian nilai batas (BVA) mencakup batas minimum dan maksimum nominal transaksi.
- [ ] Seluruh data nasabah pengujian disanitasi (Zero PII).
