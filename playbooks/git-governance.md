# 🌿 Playbook: Git Governance & Multi-Branch Safety — Yerly-Playground 🌸

Tata kelola Git, manajemen commit, dan sinkronisasi branch aman untuk tim QA Bank Mega.

---

## 1. Aturan Commit & Push Aman
1. Selalu periksa `git status` sebelum melakukan staging untuk mencegah file temporer masuk ke repository.
2. Gunakan pesan commit konvensional:
   - `feat:` penambahan skrip / skenario baru.
   - `fix:` perbaikan locator atau logika test flow.
   - `docs:` pembaruan dokumentasi atau catatan memori.
   - `chore:` pemeliharaan konfigurasi / dependensi.

---

## 2. Multi-Account Identity Standard
- Repositori `yerlymega/Yerly-Playground`: Konfigurasi nama dan email lokal ke akun yang sesuai agar author commit tercatat rapi di GitHub.
