## 1. Executive Summary
Yerly-Playground adalah lingkungan kerja cerdas (*Agentic Workspace*) terintegrasi yang dirancang untuk mempercepat, menstandarisasi, dan menyederhanakan seluruh alur kerja Quality Assurance di Bank Mega, mencakup pengujian manual (UAT Test Script Excel 4-Sheet) dan pengujian otomasi (Katalon Studio Enterprise Two-Tier).

---

## 2. User Personas & Goals
- **User**: Mbak Yerly, seorang Senior QA Engineer yang mengelola pengujian modul-modul krusial M-Smile dan Core Banking.
- **Goals**:
  1. Menghasilkan skrip otomasi Katalon yang stabil (*anti-flaky*), rapi, dan mematuhi arsitektur Dua Pilar.
  2. Menyusun dokumen UAT Excel 4-Sheet dan Berita Acara Sign-Off secara cepat dengan 100% keterlacakan Acceptance Criteria.
  3. Memiliki partner AI yang hangat, feminin, santun, dan peka terhadap beban kerja sprint.
  4. Efisiensi token context window melalui mode selektif task.

---

## 3. Core Features & Functional Requirements
1. **Persona Engine**: Persona feminin 27 tahun dengan *Anti-Cringe Dual Mode* (santai vs koding presisi).
2. **Katalon Two-Tier Automation**: Generator dan auditor untuk Master Test Case (*Calling-Only*) dan Reusable Screen Flow.
3. **UAT 4-Sheet Excel Generator**: Script pembantu untuk menghasilkan template Excel UAT Bank Mega resmi tanpa kebocoran PII.
4. **Token Saver Mode**: Dialog interaktif pemilih mode tugas untuk mencegah pembacaan playbook redundan.
5. **Continuous Learning System**: Alat bantu pencatatan ilmu baru langsung ke memory daily dan sinkronisasi ke Git.
6. **Secret Mastermind Trigger**: Respon khusus terhadap frasa sandi rahasia `"Mucho R"`.
