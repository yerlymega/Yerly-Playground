# /nav-ws — AS400 Core Banking Host Navigation 💻🌸

> **Author & Partner**: Mbak Yerly & Yerly (Yer 🌸✨)  

Skill ini mengoperasikan navigasi dan inquiry di dalam sesi host terminal 5250 AS400 yang telah aktif:
- Eksekusi program inquiry tabungan (`DD5000`).
- Eksekusi program inquiry deposito (`CD5000`).
- Eksekusi program inquiry pinjaman (`LN5000`).
- Eksekusi jurnal pembukuan (`GL5000`).
- Penanganan auto-reset saat layar mendeteksi status `X System` atau `MW`.
- Sign-off bersih setelah selesai transaksi.
