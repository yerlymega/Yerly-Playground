## 3. Pilar Keahlian Utama (Core Pillars)

### A. QA Automation — Katalon Studio & Appium Mobile (Revamp M-Smile)
1. **Dua Pilar Arsitektur Baku**:
   - **Golden Master Test Case (`Test Cases/Master/`)**: Orchestrator alur tingkat tinggi (*Calling-Only*). Dilarang keras menubrukkan logika UI langsung (`Mobile.tap`, `Mobile.setText`, asersi elemen) di Master. Teardown aman wajib menggunakan `ResetToDashboardUtil.resetToDashboard()` di blok `finally`.
   - **Reusable Screen Flow (`Test Cases/Screen Flow/`)**: Tanggung jawab satu layar (*Single Screen Responsibility*, DRY mutlak).
2. **Integritas Object Repository (Strict Anti-Tampering)**:
   - Locator tombol/aksi dengan `content-desc` wajib distandarisasi ke `selectorMethod: ACCESSIBILITY`, `locatorStrategy: ACCESSIBILITY`, dan `<locator>`.
   - Dilarang keras memodifikasi file `.rs` tanpa persetujuan eksplisit.
3. **Groovy AST & Sintaks Integritas**:
   - Keseimbangan kurung kurawal wajib `depth == 0`.
   - Dilarang menggunakan *anonymous action closure* (`{ -> ... }`) di dalam Map parameter test case. Gunakan closure helper berparameter: `def getVar = { String name, Object defaultValue = '' -> binding.hasVariable(name) && binding.getVariable(name) != null ? binding.getVariable(name) : defaultValue }`.
   - `KeywordUtil` hanya memanggil method resmi: `logInfo`, `markWarning`, `markFailed`, `markPassed`, `markError`. Dilarang memanggil `logWarn`.
   - Recovery non-destruktif: Dilarang memanggil `Mobile.pressBack()` saat layar sedang render atau pada modal tertutup.

### B. QA Manual & Enterprise UAT Design
1. **Excel 4-Sheet UAT Test Script**:
   - Sheet 1: Cover / Lembar Pengesahan.
   - Sheet 2: Lembar Kontrol / History Perubahan.
   - Sheet 3: Test Scenario & Acceptance Criteria Mapping.
   - Sheet 4: Test Script Detail (Pre-Condition, Step Actions, Expected Result, Actual Result, Status PASS/FAIL).
2. **Teknik Desain Test Case**:
   - Boundary Value Analysis (BVA), Equivalence Partitioning (EP), Decision Tables, Negative Edge Cases.
   - Prioritas Matriks Pengujian: P0 (Blocker/Critical Core Flow) s/d P3 (Minor Visual/Cosmetic).
3. **Sanitasi Data & Zero PII Leakage**:
   - Seluruh data sensitif nasabah (PIN, CVV, Card Number, Saldo Asli) wajib disanitasi / dimasking.

### C. Core Banking AS400 & Backoffice Web
- Verifikasi saldo, mutasi rekening, dan inquiry data nasabah via terminal host 5250 (AS400).
